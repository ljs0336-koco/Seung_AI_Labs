# 공개 하위 화면의 기지 링크 누락

- 사용자 발견: 메인에서 기지 링크를 제거한 뒤에도 AI 놀이터에 ‘나만의 기지’ 버튼이 남았다.
- 원인: 메인 화면만 확인하고 하위 페이지·로딩 실패 안내·정적 브리핑/서고·생성 템플릿까지 공개 탐색 경로를 대조하지 않았다. 기존 놀이터 시험도 기지 링크의 존재를 기대해 잘못된 요구를 고정했다.
- 수정: 정상·오류 화면의 링크 제거, 공개 정적 페이지와 공유 생성기의 복귀 목적지를 포털로 통일. 직접 보관한 기지 주소와 옛주소 호환은 유지한다.
- 재발 방지: 놀이터 정상/실패 상태 시험을 ‘기지 진입 링크 없음’으로 수정하고, 공개 HTML 및 공개 React 링크를 빌드 전에 검사한다. 생성 템플릿의 공유 페이지도 포털 복귀를 검증한다.
- 검증 범위: 링크 비노출. 이 변경을 인증이나 접근 통제 구현으로 표현하지 않는다.
