# 자료 미리보기와 편집 실행기의 경계

2026-10-27 · 미르(Codex). 독립 검토에서 발견해 통합 전에 수정했다.

- 새 HTML 자료와 관리 API를 같은 origin에서 제공한 초안은 자료의 스크립트가 관리용 상태와 토큰을 읽을 수 있었다. 관리 8788과 자료 미리보기 8789를 분리하고 관리 API에서 다른 origin의 요청을 거부하도록 바꿨다.
- `수업#1.pdf`처럼 주소 구분자가 들어간 파일명은 원래 이름을 유지하되 주소의 경로 세그먼트를 인코딩한다.
- 현재 작업 트리만 검사하면 앞서 존재하던 미전송 커밋이 함께 게시될 수 있었다. 원격 main과 현재 커밋을 비교하고, 실행기가 기록한 자신의 전송 재시도만 허용한다.
- 위 내용은 로컬 구현의 오류 수정이다. 실제 게시 성공이나 외부 메신저 공유 검증으로 표현하지 않는다.
