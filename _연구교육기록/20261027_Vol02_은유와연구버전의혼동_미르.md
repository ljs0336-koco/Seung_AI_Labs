# Vol.02: 은유와 연구 버전이 만든 이해의 혼동

사용자가 문구·단어·맥락의 모호함을 지적하여 8쪽을 독립 검토했다. 원본과 사용자 피드백은 구분하여 보존했다.

발견: ‘고르는 손’이 초안 선택·유급 평가·일반 사용자 반응·자료 정제·국가 사업 평가를 모두 가리켰다. 작은 단서는 반영 비율이 미공개라고 했지만 큰 ‘쓸 때마다 1표’와 화살표는 즉시 학습을 연상시켰다. 사용자가 제공한 경험은 창의성보다 원자료와 말투가 남은 초안을 골랐다는 것이며, 이 선택이 곧 모델 학습이었다는 증거는 아니다.

근거 대조: 현재 공개 Convovo 논문은 정당 후보를 지목한 응답 중 92%·97%를 보고한다. 전체 질문·선거구 비율로 쓰면 분모가 바뀐다. 원고의 검색 미사용 30건 세부 값은 현재 원문에서 재확인되지 않아 제거했다. 과거 보도 값이 틀렸다고 단정한 것이 아니라 원문 버전·분모를 확인해 현재 게시 문장을 좁힌 조치다.

수정: 실제 제안서 초안 선택 경험과 현실적 제약·위기·대비책이라는 사용자 뜻을 본문에 반영한다. 통제 가능한 범위에서 목적에 맞게 AI를 쓰고 싶다는 관점과 소버린 AI의 제도적 개념을 구분한다. 새 원고도 독립 편집 검토와 8쪽 지면 확인을 각각 거친다.

다음 작업의 확인점: 표제·도식의 단정이 작은 각주보다 강하지 않은가? 다른 측정의 수치를 같은 지표처럼 묶지 않았는가? 사람이 확인했다는 기록과 실제 사용자가 이해했다는 결과를 구분했는가?

## 조립 중 발견한 스크립트 오류

미르가 공유 메타데이터를 넣으며 `</title>` 전체 치환을 사용했다. SVG 차트 제목을 만드는 인라인 JavaScript 문자열에도 같은 표식이 있어 스크립트 구문이 깨졌고, 실제 브라우저에서 다음 슬라이드 버튼이 작동하지 않았다. 공개 전 미리보기에서 발견해 사용자에게 알렸으며 치환을 문서 머리말 한 곳으로 제한했다. Vite는 public의 정적 HTML 스크립트를 컴파일하지 않으므로 production build 통과만으로는 발견하지 못한다. `scripts/check-magazine.mjs`를 정식 build 흐름에 추가해 인라인 스크립트 구문, 메타데이터 개수, 8쪽 구성, 포털 복귀 링크를 검사한다. 실제 8쪽 버튼·키보드·해시 이동은 별도로 확인한다.
