# 동적인 지도에서도 노출·초점·움직임을 따로 확인하기

2026-10-27. 목표는 평면 카드 포털을 세 구의 느린 공전 지도로 바꾸면서 공유·노출 기능을 보존하는 것이었다.

독립 검토자는 헤더의 서고 링크가 노출 설정을 따르지 않는 점, 간행물을 모두 숨겼을 때 남는 이동 버튼, 긴 제목의 잘림 가능성을 찾았다. 이어 키보드로 간행물로 이동해도 초점은 앞쪽에 남는 점을 확인했다. 구현 담당자는 지도 전체의 hover/focus 정지가 공전 재개 버튼에도 적용되는 UX 혼동을 제기했다.

노출 조건을 공통 적용하고, 간행물 버튼은 대상이 있을 때만 표시하도록 수정했다. HashRouter의 hash 이동 대신 section 스크롤과 초점 이동을 함께 처리했다. 행성 제목은 시각적으로 두 줄로 제한하되 전체 접근성 이름과 툴팁을 보존한다. 임시 정지는 지도와 행성 링크로 한정해 툴바 재개가 즉시 동작하게 했다.

실제 브라우저에서 시간에 따른 위치 변화, 정지 시 animation-play-state, 재개 후 running을 확인했다. 390px에서는 정적 삼각 별자리와 가로넘침 없는 기지 검색을 확인했다. 이는 사용자 선호의 최종 승인이나 모든 보조공학 환경의 사용성 검증을 뜻하지 않는다.

수업 질문: 애니메이션이 보이는 것과 사용자가 목적지를 쉽게 선택하는 것은 어떻게 다른가? 재현 실습: 움직이는 링크와 정지 버튼을 같은 focus-within 영역에 넣고 재개 후 상태를 비교한다. CSS 위치 확인과 키보드 이동을 별도로 기록한다.
