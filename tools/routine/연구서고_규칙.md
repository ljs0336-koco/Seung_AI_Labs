# 연구 서고 갱신 규칙

연구 다이제스트 루틴은 보고서와 `논문_누적목록.md`를 저장한 뒤, 오늘 다룬 연구를 공유용 '연구 서고'에 들인다. 서고는 날짜별 보고서가 아니라 계속 쌓이는 도서관이다. 사용자가 논문·학술지 원고에 인용하려고 모으는 자료이므로 **서지 정보의 정확성**이 가장 중요하다.

- 원본 데이터: `<루틴 폴더>\02_연구논문\연구서고.json` (`items` 끝에 추가)
- 만들기: `python "<루틴 폴더>\_도구\build_library.py"` → `<루틴 폴더>\research-library\` (index.html, library.bib, library.ris)
- 디자인은 `research-library\assets\library.css`만 고친다. HTML·bib·ris는 매번 새로 만들어진다.
- 공개 위치: 사용자 GitHub `Seung_AI_Labs` 저장소의 `public/library/` (브리핑과 별도 공유용 페이지)

## 공개 범위

공개 페이지다. **넣지 않는 것:** 우리 팀 강의·특강 일정과 장소, 학교·기관 이름, 내부 프로젝트·교재 이름, 저자 외 사람 이름, 사용량. 다이제스트의 '💡 우리 수업·교재에 적용할 아이디어'는 그대로 옮기지 않고, 누구나 읽어도 되는 일반적인 '교육적 시사점'으로 다시 쓴다.

## 정확성

- 저자는 **전체 목록**을 초록 페이지에서 확인해 넣는다(arXiv는 `citation_author` 순서 그대로). '외'로 줄이지 않는다. 한국인 저자는 `["홍", "길동"]`처럼 한글로 쓴다(인용문에는 '홍길동'으로 나온다).
- 프리프린트와 출판본이 모두 있으면 출판본으로 한 번만 넣고, 프리프린트는 `extra_links`에 `{"label": "arXiv 판", "url": "…"}`로 단다.
- 날짜·발표처·DOI·쪽수는 이번 실행에서 확인한 것만 쓴다. 학회 채택만 확인되고 논문집 DOI가 없으면 arXiv 판으로 인용하고 `note`에 적는다.
- arXiv 논문은 DOI를 따로 적지 않아도 된다. 만들기 스크립트가 `10.48550/arXiv.<번호>`를 쓴다.
- 같은 연구(DOI·arXiv 번호·URL이 같음)가 이미 있으면 추가하지 않는다. 만들기 스크립트도 중복이면 멈춘다.
- 기존 항목은 지우거나 번호를 바꾸지 않는다. 고칠 때는 그 항목만 고치고 `verified`를 오늘 날짜로 바꾼다.

## 항목 형식

```json
{
  "no": "015",                      // 등록번호: 기존 최대값 + 1, 세 자리
  "shelf": "C",                     // 주 서가 기호(아래 표)
  "also": ["D"],                    // (선택) 함께 꽂을 서가
  "added": "YYYY-MM-DD",            // 서고에 들인 날(오늘)
  "verified": "YYYY-MM-DD",         // 서지 확인한 날
  "kind": "preprint",               // journal | conference | workshop | working-paper | report | book | magazine | preprint
  "cite_as": "arxiv",               // arxiv | proceedings | journal | report | book | repository
  "edition": "3rd",                 // (선택) 책의 판차 → APA '*제목* (3rd ed.).'
  "title": "원제(원문 표기 그대로)",
  "title_sentence": "APA용 문장형 대소문자 제목(첫 글자·콜론 뒤 첫 글자·고유명사·약어만 대문자)",
  "title_ko": "국문 번역 제목",
  "spine": "책등에 쓸 짧은 제목(영문 25자 안팎)",
  "authors": [["성", "이름"], ["Kim", "Jinhee"]],   // 기관 저자는 [["OECD", ""]] + "org_author": true
  "year": 2026, "date": "YYYY-MM-DD",
  "updated": "YYYY-MM-DD", "version": "v3",        // (선택) 개정판
  "venue": "화면에 보일 발표처(예: arXiv 프리프린트, CHI 2026 (ACM))",
  "arxiv": "2609.29995", "arxiv_class": "cs.HC",   // arXiv에 있으면
  "doi": "10.1145/...",                              // 확인한 DOI만
  "container": "논문집·저널 이름", "publisher": "출판사·기관", "pages": "3763–3779",
  "volume": "", "issue": "",                         // 저널일 때
  "series": "NBER Working Paper", "number": "35621", // 보고서·워킹페이퍼일 때
  "bib_note": "(선택) BibTeX note, 영어. 예: 학회 채택 정보",
  "url": "원문(초록) 페이지",
  "extra_links": [{"label": "EU 소개 글", "url": "..."}],  // (선택)
  "design": "연구 설계", "sample": "대상·표본",
  "population": ["중학교"],          // 초등학교 | 중학교 | 고등학교 | 대학 | 교사 | 일반 | 정책
  "keywords": ["키워드 3~5개"],
  "question": "핵심 연구 질문 한 문장",
  "findings": ["주요 결과 2~3문장"],
  "implications": ["일반적인 교육적 시사점 1~3문장(내부 일정·이름 없이)"],
  "limits": "한계 한 문장",
  "article": "805",                  // (선택) 쪽 대신 논문 번호를 쓰는 학술지. pages는 비운다 → APA '5, Article 805.'
  "basis": "원문 기준 | 본문 일부 기준 | 초록 기준 | 요약 페이지 기준",   // 첫 단어로 카드의 확인 범위 배지가 정해진다(원문 확인 / 본문 일부 확인 / 초록 기준 / 요약 기준)
  "note": "(선택) 날짜 불일치, 인용 시 주의점",
  "see_also": ["010"],               // (선택) 함께 볼 기존 자료 등록번호
  "source": "special", "batch": "SR1", "curator": "마루"   // 특별리서치 자료만
}
```

`cite_as`별로 필요한 칸: arxiv → `arxiv` / proceedings → `container`, `publisher`, `doi`(있으면 `pages`) / journal → `container`, `volume`, `issue`, `pages`, `doi` / report → `series`, `number`, `publisher` / book → `publisher` / repository → `publisher`, `number`.

## 서가

| 기호 | 서가 | 넣는 연구 |
|---|---|---|
| A | AI 리터러시·시민성 | 학생·교사의 AI 이해·비판적 판단·활용·참여 역량 |
| B | 교사 AI 역량·연수 | 교사·예비교원 AI 역량, 연수 설계와 효과 |
| C | AI 튜터링·학습 지원 | AI 튜터·조교·챗봇의 학습 지원 |
| D | 바이브코딩·AI 협업 코딩 | LLM과 함께 코딩하기, 프로그래밍 교육 |
| E | 교육용 로봇·피지컬 컴퓨팅 | 로봇·블록코딩·AI 교구 |
| F | 교육 정책·제도 | 국가·학교 AI 도입 정책과 제도, 정책 보고서 |
| G | AI의 학습 영향 | 생성형 AI가 학습·인지·비판적 사고·학습 격차에 미치는 영향과 AI 의존(AI Impacts) |
| H | 책임 있는 AI·아동 안전 | 아동의 권리, 개인정보·감시, 편향·공정성, 아동 안전, 규제·거버넌스, 비판적 교육공학 |
| I | 이론적 기반 | 스캐폴딩·인지적 도제·자기조절·행위주체성 등 연구 해석의 바탕이 되는 학습 이론(고전 포함) |
| J | 연구방법·측정도구 | 사례연구·질적 보고 기준·면담·주제분석·사전사후 설계 등 연구방법, 타당화된 측정 척도 |

나눌 때 헷갈리면: 학습 효과 자체를 묻는 연구는 G, AI 정책 보고서와 국가·학교 도입 정책은 F, 윤리·권리·규제는 H, 학생·교사가 AI를 따져 쓰는 힘(리터러시)은 A.
자료가 없는 서가는 페이지에 보이지 않는다. 어느 서가에도 맞지 않는 주제가 계속 나오면 `shelves` 끝에 다음 기호(I…)로 새 서가를 더하고 보고서에 적는다. 기존 서가 기호는 바꾸지 않는다(청구기호가 바뀐다).

## 특별리서치(정기 다이제스트 밖에서 따로 조사한 자료)

사용자가 주제를 정해 Perplexity 등으로 따로 조사한 자료는 '특별리서치'로 표시한다. 페이지에서는 책등에 붉은 책갈피, 카드에 '특별리서치' 표시가 붙고, '수집 경로' 필터와 바닥글의 '수집 경로' 목록에 회차가 나온다.

- 회차는 최상위 `batches`에 한 번 적는다.
  ```json
  "batches": [
    {"id": "SR1", "name": "특별리서치 1차", "date": "YYYY-MM-DD",
     "topic": "AI Impacts · K-12 · Responsible AI", "method": "Perplexity 학술 검색 결과를 원문 대조 후 정리"}
  ]
  ```
- 그 회차의 자료마다 `"source": "special"`, `"batch": "SR1"`, `"curator": "마루"`(정리한 사람)를 넣는다. 정기 루틴 자료에는 이 칸을 넣지 않는다.
- 등록번호는 정기 자료와 같은 번호 줄을 이어 쓴다(별도 번호 체계를 만들지 않는다).
- 조사 원자료(Perplexity 결과 전체, 논쟁 지도, 연구 공백)는 공개 페이지에 넣지 않고 `02_연구논문/특별리서치/`에 보관한다.

## 기지 연결 요약 (2026-10-27)

- `build_library.py`가 `research-library/summary.json`을 HTML·BibTeX·RIS와 함께 만든다. 게시 도구는 `public/library/summary.json`으로 복사한다.
- total=전체 등록 자료 수, reviewed=journal/conference 자료 수(본문 확인 편수와 다름), special=특별리서치 편수다.
- shelves는 주 서가 기준 편수다. 같은 자료의 `also`는 검색·서가 필터에만 함께 반영한다.
- recent는 등록일·등록번호 내림차순 5편이다. items는 전체 자료 검색 레코드(id/code/call/title/titleKo/authors/year/kind/href/keywords/shelves)다.
- 등록번호(no)는 유지한다. No.046은 주 서가 H와 함께 꽂기 A로 분류하며, 010 +G, 013 +G·H, 014 +G, 042 +A, 043 +G를 반영한다. 서가 이름 변경 전 용어도 검색 별칭으로 유지한다.
