# KANSAI NOTES

겨울 간사이 3박 4일 여행가이드 두 가지입니다.

- index.html: 가이드 선택
- couple.html: 느긋한 커플 — 오사카 3연박, 교토 버스투어 하루
- pokemon.html: 포켓몬 팬과 친구 — 오사카 2일·교토 2일, 오사카 2박·교토 1박

## 보기

index.html을 브라우저로 열면 됩니다. 각 가이드의 CSS·JavaScript·SVG가 HTML 안에 있어 couple.html 또는 pokemon.html 하나만 저장해도 본문을 볼 수 있습니다. 인터넷 없이 본문을 볼 수 있지만 지도·예약·공식 사이트는 인터넷이 필요합니다. 휴대폰에서는 브라우저에서 연 뒤 홈 화면에 추가하거나 파일로 보관하세요. 설치형 앱·서비스워커 캐시는 아닙니다. 일부 휴대폰 파일 미리보기에서는 JavaScript가 제한될 수 있으며 브라우저에서 열어야 일자 탭과 체크 저장을 쓸 수 있습니다.

## 공유

이 폴더의 네 파일만 GitHub 저장소에 올리고 Settings → Pages에서 게시할 브랜치와 root를 선택하면 됩니다. 기존 저장소의 하위 폴더에 넣는다면 해당 경로/index.html로 접근합니다. 저장소 전체나 개인 원문을 함께 올리지 마세요. 현재는 로컬 제작본이며 실제 게시·예약·결제를 하지 않았습니다.

## 여행 가정과 정보 범위

- 겨울 12–2월, 성인 2명, D1 간사이공항 12시 도착·D4 19시 이후 출발 기본안. 특정 여행일은 확정하지 않았습니다.
- 장소 정보 확인일: 2026-10-22. 운영시간·연말연시 휴무·판매일·재고는 방문 직전 공식 확인이 필요합니다. 2026년 말~2027년 초의 확정 특별 영업표는 확보하지 않았습니다.
- 교토 2곳 투어는 더 느긋한 우선 후보이나 여행일의 판매·최소출발·출발 시각은 확인 전입니다. 실제 판매 일정이 없다면 연결된 3곳 상품을 비교합니다. 투어 내부 순서·체류는 운영자 바우처가 기준입니다.
- 호텔은 위치·동선 추천입니다. 실제 날짜의 가격·빈방은 확인하지 않았습니다. 표의 비용·도보·소요시간은 계획용 추정이며 개인 여행 실적을 사용하지 않았습니다.
- 포켓몬센터 오사카는 현재 공식 안내상 LUCUA SOUTH 13F, 오사카 DX는 다이마루 신사이바시 9F, 교토센터는 SUINA 무로마치 2F입니다. 공식 매장 버튼에 근거를 연결했습니다.
- 카페 예약은 월별 공식 NEWS와 Osaka 예약 안내를 따릅니다. 예전 “31일 전 18시” 규칙을 고정 적용하지 않습니다. 좌석·카드·한정 상품 재고를 보장하지 않습니다.

## 개인정보와 권리

이름·연락처·실제 여행 날짜·개인 지출·거래·예약·원본 사진·파일 경로를 포함하지 않습니다. 분석·광고·외부 폰트·자동 지도 요청이 없습니다. 체크리스트는 브라우저 localStorage에 체크 여부만 저장하고 서버로 전송하지 않습니다. 외부 지도·예약 링크를 누르면 해당 서비스 정책이 적용됩니다. 원문 자료는 이 폴더에 없습니다.

독립 제작 여행 제안이며 매장·브랜드의 공식 안내서가 아닙니다. Pokémon 등 상표의 권리는 권리자에게 있습니다. 공식 캐릭터 이미지와 로고를 쓰지 않았고 일러스트는 직접 구성한 벡터입니다. 별도 사진 다운로드나 외부 자산이 필요하지 않습니다.

## 화면 기능

- 일자별 일정 전환, 전체 일정 보기, 키보드 좌우/Home/End 이동
- 주소가 포함된 Google Maps 검색, 공항·도시 간 대중교통 경로
- 숙소 공식 예약·식당 공식 안내·클룩 실상품 링크
- 장소 검색, 준비 체크 저장/초기화, 포켓몬센터 방문 체크
- 인쇄·PDF 버튼 (네 날 일정이 모두 출력되도록 인쇄 스타일 적용)
- JavaScript를 꺼도 네 날 일정 본문과 링크 표시

체크 저장은 브라우저·주소별로 다를 수 있고 사생활 보호 모드나 파일 미리보기에서는 제한될 수 있습니다.
