AI 에이전트 · Anthropic·TechCrunch · 영문 기사 · 10/22(목)

Anthropic, 비서형 에이전트 앱 'Claude Duet' 연구 프리뷰 공개

  • Anthropic이 10월 22일 아침 브리핑, 할 일 제안, 회의 잡기·대시보드 만들기 등을 대신하는 에이전트 앱 Claude Duet을 연구 프리뷰로 공개했습니다.
  • 자체 클라우드 컴퓨터에서 6,000개 이상의 커넥터·플러그인과 연결해 일하며, Opus 5.5 모델을 씁니다.
  • 미국의 Pro·Max 구독자가 대기자 명단으로 쓸 수 있고, iOS·Android 앱과 웹을 지원합니다.
  • 메시지 발송·결제 전에는 사용자 승인을 받고, 카드번호·신분증 요청은 기본 거절하며 증권 거래·계좌 이체는 하지 않습니다.
  • 회사는 대화를 잘못 읽거나 긴급도를 잘못 판단할 수 있다고 밝혔고, 연령 기준은 공개하지 않았습니다.

우리 팀 메모에이전트에게 맡길 일과 사람이 승인할 일을 나누는 수업 활동 소재로 쓸 수 있습니다.

AI 에이전트 · TechCrunch · 영문 기사 · 10/22(목)

1Password, AI 에이전트가 비밀번호를 보지 않고 대신 로그인하는 기능 출시

  • 1Password가 10월 22일 '1Password for Agents'를 내놨습니다.
  • 에이전트가 디지털 키로 자신을 증명하면 사용자에게 알림이 가고, 사용자가 승인해야 1Password가 대신 로그인합니다.
  • Claude Duet, ChatGPT Work, Meta Muse 등 여러 에이전트를 지원 대상으로 들었습니다.
  • 권한 범위 설정, 접근 철회 방법, 가격은 기사에 나오지 않았습니다.

우리 팀 메모에이전트에게 비밀번호를 직접 주지 않는다는 원칙을 가르치는 사례입니다.

AI 에이전트 · Anthropic · 영문 기사 · 10/22(목)

Anthropic, 'Agent Skills' 표준을 리눅스재단 산하 재단에 기증

  • Anthropic이 Agent Skills 표준과 이름·도메인·GitHub 조직을 Agentic AI Foundation에 넘겼습니다.
  • 이 재단은 리눅스재단 산하로, Anthropic·Block·OpenAI가 함께 세웠고 앞서 MCP도 기증받았습니다.
  • ChatGPT, Cursor, GitHub Copilot, VS Code 등 70개 이상 플랫폼이 이미 이 표준을 지원합니다.
  • 앞으로 버전별 릴리스, 공식 제안 절차, 스킬 설치 보안 지침을 만들 계획입니다.

우리 팀 메모한 번 만든 스킬을 여러 AI 코딩 도구에서 함께 쓸 가능성이 커졌습니다.
