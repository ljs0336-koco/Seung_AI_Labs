# TeacherMate 업무 지도 개선 시연 앱 (공공 업무 대장형)

로그인이나 서버·API 연결 없이 **업무 지도 한 화면**의 정보 구조(IA), 반응형 배치, 필터·수합 상세 복귀 흐름을 바로 눌러 볼 수 있도록 만든 정적 웹 시연 앱입니다.

- **가상 학교 데이터 전용**: 학교명(`예시초등학교(가상)`), 일정, 문서 번호(`예시문서-1101`~`1201`), 폴더 경로는 모두 새로 만든 가상의 예시입니다.
- **무인증 정적 구조**: 실제 공문, 학교 자료, 계정, API 키, 백엔드 호출이나 외부 DB 연동을 포함하지 않습니다.

## 1분 시연 순서

1. **첫 화면 확인 (`예시초등학교(가상)`)**
   - 상단 주 메뉴가 4개(`업무 지도`, `자료 올리기`, `인수인계`, `업무 질문`)와 단일 `[설정]` 버튼으로 정돈되어 있습니다.
   - 담당 필터가 `[담당 전체 업무 ▾]`로 접혀 있고, 데스크톱은 표 대장(`마감일 | 업무명 | 담당 | 구분 | 상태 | 진행`), 모바일은 2줄 목록이 스크롤 없이 첫 화면에 바로 보입니다.
2. **담당 선택 (`1학년 담임`)**
   - `[담당 전체 업무 ▾]`를 열고 `1학년 담임`을 선택합니다.
   - `담당 해제 ×` 버튼과 `적용 조건: 담당 1학년 담임 (4건)` 요약이 나타나며 목록이 4건으로 좁혀집니다.
3. **수합 업무 상세 열기 (필터 유지 확인)**
   - 데스크톱 오른쪽 `수합 현황` 패널(모바일은 상단 `수합 현황 · 3건 진행 중` 펼치기)에서 `동절기 교실 난방기·멀티탭 안전점검표 수합`을 누릅니다.
   - 목록 필터(`1학년 담임`)는 유지된 채 상세 서랍이 열리며, 상단에 필터 유지 안내 배너와 `교내 메신저 안내 문구 복사` 버튼이 표시됩니다.
4. **서랍 닫고 보던 목록·스크롤·초점 복귀 확인**
   - 상단 `닫기`, 하단 `닫고 1학년 담임 목록으로 돌아가기`, 또는 키보드 `Esc`로 닫으면 보던 `1학년 담임` 목록과 스크롤 위치, 누른 수합 버튼의 키보드 초점이 그대로 돌아옵니다.
5. **휴대폰(`390×844`) 화면 확인**
   - 브라우저 폭을 390px로 줄이거나 스마트폰으로 열면, 상단 메뉴 4개가 한 줄에 잘리지 않고 들어가며 `수합 현황`이 접힌 상태로 시작해 첫 화면에서 바로 업무 목록을 볼 수 있습니다.

## 공공 업무 대장형 UI 정돈 내역

- **서체·크기**: Pretendard GOV 기반 `16px` 본문과 5단계(`13·14·16·18·22px`) 크기, 3단계(`400·600·700`) 굵기 및 숫자 열 `tabular-nums` 정렬
- **형태·그림자**: 버튼·입력 `4px`, 패널 `6px` 각진 모서리 통일(`999px` 알약 제거), 서랍·모달·팝오버 등 겹침 요소에만 그림자 적용
- **색상·상태**: 남색(`#1e4e8c`)과 무채색 계층 중심, 상태 강조는 `기한 초과`(빨강 글자 및 행 좌측 3px 선)와 `AI 초안`(주황 테두리 태그) 두 가지만 유지
- **진행·완료 표시**: 취소선과 체크박스 대신 회색 `완료` 태그 사용, 수합 진행률은 가는 남색 막대와 `4/6 제출` 숫자 표기(기한 경과 미제출 시에만 빨강)
