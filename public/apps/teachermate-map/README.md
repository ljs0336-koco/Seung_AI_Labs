# TeacherMate 업무 워크스페이스 개선 시연 앱 (전 화면 구현판)

로그인이나 서버·API 연결 없이 **업무 지도(목록 대장·월간 캘린더), 자료 올리기(원문 대조 검수), 인수인계 노트, 업무 질문(근거 검증·가드레일), 환경설정** 전 화면과 연동 흐름을 바로 눌러 볼 수 있도록 만든 정적 웹 시연 앱입니다.

- **가상 학교 데이터 전용**: 학교명(`예시초등학교(가상)`), 일정, 문서 번호(`예시문서-1018`~`1205`), 폴더 경로는 모두 새로 만든 가상의 예시입니다.
- **무인증 정적 구조**: 실제 공문, 학교 자료, 계정, API 키, 백엔드 호출이나 외부 DB 연동을 포함하지 않습니다.

## 구현된 주요 화면 및 개선 포인트

1. **업무 지도 (`목록 대장` · `월간 캘린더`)**
   - 구글 캘린더·워크스페이스 감각의 구분 라벨(색상 점), 부드러운 카드 음영, 클릭 가능한 체크박스(`✓`) 제공
   - 상단 `[목록 대장 | 월간 캘린더]` 전환 버튼으로 주간 대장 표와 7열 월간 캘린더 격자를 자유롭게 오가며 확인
   - 담당 필터(`전체 업무 ▾`)를 접어 첫 화면(데스크톱 `1440px`·모바일 `390px`)에서 바로 업무 목록 확인
   - `1학년 담임` 필터 유지 상태에서 수합 상세 서랍을 열고 닫으면 보던 목록·스크롤·키보드 초점이 그대로 복귀
2. **자료 올리기 (원문 ↔ 초안 좌우 대조 · 명단/개인정보 차단)**
   - `학사력 불러오기`와 `자료 → 업무 변환`을 한 화면 탭 2개로 통합
   - 공개 시연에서는 외부 AI 호출 없이 날짜·키워드 규칙으로 후보를 추출하며(`시연용 규칙 추출` 표기), 올린 자료는 브라우저 밖으로 전송되지 않음
   - 붙여넣은 본문과 `.txt/.csv` 파일 모두에서 개인정보 패턴 및 `[이름·학번·연락처]` 학생 명단 열을 감지하면 즉시 차단(`차단 시험 · 학생 명단 CSV` 버튼으로 1클릭 확인 가능)
   - 왼쪽 원문에서 추출 근거 줄을 하이라이트로 대조하고, 오른쪽 초안 카드를 수정한 뒤 `업무 지도`에 즉시 반영
3. **인수인계 노트 (연간 흐름 · 전임자 Q&A · `?reply=` 1회용 답변 화면)**
   - 6개 학년·부서별 연간 주요 시기, 실무 요령, 연결된 올해 업무 서랍 열기, `.txt` 내려받기 지원
   - 학교 밖 전보 교원을 위한 `1회용 답변 링크(?reply=<카드id>)` 복사 및 직접 열기·회신 반영 지원
4. **업무 질문 (주제어 기반 근거 검증 · 추측 방지 가드레일)**
   - 다른 탭에 다녀와도 대화가 유지되며, `2학기 학예 발표회...` 같은 질문이 `2학년 담임`으로 잘못 매칭되지 않음
   - `마감`·`제출`·`평가` 등 일반 낱말만으로 과신하지 않고 질문의 핵심 주제어가 문서에 있을 때만 `✓ 문서 근거 확인`을 표시, 없는 업무(`성과상여금 평가 기준표`, `텃밭 퇴비`, `독감 예방접종`, `주차장 비밀번호`)는 `확인 필요 · 연관 근거 없음`으로 분리
   - `300자` 입력 제한 및 휴대전화·주민등록번호·이메일 등 개인정보 입력 사전 차단
5. **설정 (내 담당 지정 · 실시간 집계 · 발표 시연 도구 분리)**
   - 올해 내 담당 학년·부서를 체크하면 업무 지도의 `내 담당` 필터 및 `.ics` 내보내기와 즉시 연동
   - `발표용 시연 보조 도구` 토글을 끄면 일반 교사 화면만 보이고, 켜면 서랍 미제출 전환·예시 답변 채우기 지원
   - 공개 시연용 데이터 일괄 삭제 잠금 및 JSON 백업 내려받기 제공

## 1분 시연 순서

1. **업무 지도 목록 & 캘린더 확인**: `목록 대장`에서 체크 표시·라벨을 보고, `[월간 캘린더]`로 전환해 11월 행사·업무 배치를 확인합니다.
2. **`1학년 담임` 필터 → 수합 상세 → 복귀**: `[담당 전체 업무 ▾]`에서 `1학년 담임`을 고른 뒤 오른쪽 `수합 현황` 업무를 눌러 상세 서랍을 열고, 닫았을 때 보던 목록·스크롤·초점이 그대로 돌아오는지 확인합니다.
3. **자료 올리기 (원문 대조)**: 상단 `[자료 올리기]` 탭에서 예시 공문을 골라 왼쪽 원문 음영과 오른쪽 초안 카드를 확인하고 `검수 완료 · 확정 반영`을 눌러 지도에 추가해 봅니다.
4. **인수인계 & 업무 질문**: `[인수인계]`에서 부서 노트를 훑어보고, `[업무 질문]`에서 첫 번째 예시 질문(근거 확인)과 네 번째 예시 질문(근거 없음 방어)을 눌러 봅니다.
5. **모바일(390px) & 설정**: 브라우저 폭을 390px로 줄여 상단 4개 탭 잘림 없음과 첫 화면 목록 노출을 확인하고, 우측 상단 `[설정]`에서 내 담당 지정과 시연 도구를 살펴봅니다.
