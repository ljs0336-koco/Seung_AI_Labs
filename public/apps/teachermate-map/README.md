# TeacherMate 업무 지도 개선 시연 앱 (1차)

로그인이나 서버 연결 없이 **업무 지도 한 화면**의 개선된 정보 구조(IA), 모바일 반응형, 필터·수합 상세 흐름을 바로 눌러 볼 수 있도록 만든 정적 시연 앱입니다.

## 포함된 개선 사항
1. **모바일(390px) 및 데스크톱 레이아웃 정돈**: 상단 메뉴가 잘리거나 가로로 넘치지 않도록 4개 주 메뉴(`업무 지도`, `자료 올리기`, `인수인계`, `업무 질문`)와 단일 `[설정]` 버튼으로 단순화했습니다.
2. **담당 필터 접기**: 24개 부서 버튼 대신 `[담당: 전체 업무 ▾]` 드롭다운으로 접어 첫 화면에서 바로 업무 목록을 볼 수 있습니다.
3. **수합 업무 상세 서랍 & 목록 복귀 흐름**: `1학년 담임`처럼 특정 담당으로 좁혀 둔 상태에서 오른쪽(모바일은 상단 접이식 카드) `학교 전체 수합 현황`을 눌러도 상세 서랍이 바로 열리고, 닫으면 보던 `1학년 담임` 목록으로 그대로 돌아옵니다.
4. **가상 예시 데이터 전용**: 모든 학교명(`새솔초등학교`), 일정, 기안번호(`예시문서-1101` 등), 폴더 경로는 새로 만든 가상 예시입니다. 실제 학교 자료, 계정, API 키, 백엔드 호출을 포함하지 않습니다.
