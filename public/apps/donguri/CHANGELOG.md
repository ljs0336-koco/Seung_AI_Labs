# CHANGELOG — 돈구리

## v0.3 (2026-10-13) — 운영사 · 앱 수정 조언 반영
- [정산] 기록 없는 날을 무지출로 보상하던 문제 수정 — ‘미기록 / 무지출 확인 / 지출 기록’을 구분. 홈의 ‘오늘 안 썼어요 · 하루 마감’, ‘오늘 기록 마감’, 지난 날 ‘이날 안 썼어요’
- [정산] 지난 기록을 추가 · 수정 · 삭제하면 그날부터 다시 정산 — 더 받을 몫은 차액만, 이미 받은 도토리는 두 번 주지 않음
- [예정 지출] 날짜가 지나면 ‘썼어요 / 날짜 변경 / 안 썼어요’ 확인. ‘썼어요’는 지출로 옮기며 예정 금액을 빼서 중복 차감 없음
- [입력] 지출 고치기 · 지우기, 자주 쓰는 지출 버튼, 날짜 고르기(오늘 · 어제 · 다른 날), 저축 금액 직접 입력(부분 저축 가능, 계획 달성 때 한 번 보상)
- [홈] 오늘 한도 → ‘왜 이 금액일까?’ 계산 펼치기 → 지출 기록 → 방금 기록이 남은 돈에 어떻게 반영됐는지 → 목표 저축통 순서로 정리
- [계획 바꿔 보기] 목표일 · 목표 금액 · 고정지출을 바꿨을 때의 이번 달 저축과 하루 한도를 지금 계획과 비교한 뒤 선택
- [퀴즈] 답 뒤에 ‘내 기록과 연결’ 문장(`mine`), 틀린 문제는 도토리 없이 다시 풀어 이해 확인
- [연출] 남은 돈 숫자 변화, 도토리가 저축통으로 들어감, 목표 달성 때 돈구리 환호 — 기기의 ‘동작 줄이기’를 따름
- [디자인] 내역을 영수증처럼, 목표 카드에 저축통, 확인이 필요한 기록은 내역 탭에 점 표시
- [기록 보존] 저장 실패 안내, 기록 내보내기 · 가져오기(.json), 데모 기록을 내 기록과 분리
- [저장] `donguri_v03` — v0.2 기록 자동 이전 (받은 도토리 · 꾸미기 유지)
