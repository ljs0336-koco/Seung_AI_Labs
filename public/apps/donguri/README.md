# 돈구리 v0.2 — 오늘 써도 되는 만큼

> 2026 CODE 트랙1 · 구일고 0.91 · 운영사 제공 프로토타입
> 참으라고 하지 않고, 목표에서 거꾸로 계산해 **오늘 써도 되는 돈**을 알려 주는 게임형 경제 학습 앱

## 실행

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭합니다 (크롬 권장). 인터넷이 없어도 동작합니다 (글꼴만 기본 글꼴로 바뀜).
3. 처음 화면에서 **처음부터 설정하기** 또는 **데모로 둘러보기**를 고릅니다.
4. 휴대폰 화면으로 보기: `F12` → `Ctrl + Shift + M`

기록은 이 기기의 브라우저에만 저장됩니다. 설정(오른쪽 위 톱니) → **모두 초기화**로 처음 상태로 돌아갑니다.

## 핵심 계산 — 본선에서 설명할 수 있어야 합니다

```
오늘 쓸 수 있는 돈 = ( 한 달 용돈
                      − 고정지출
                      − 이번 달 저축액
                      − 이번 기간 남은 예정 지출
                      − 이번 기간 어제까지 쓴 돈 ) ÷ 남은 날(오늘 포함)

이번 달 저축액 = (목표 금액 − 이미 모은 돈) ÷ 목표일까지 용돈 받는 횟수   (100원 단위 올림)
```

**예시** — 목표 무선 이어폰 180,000원, 이미 45,000원, 3달 남음, 한 달 용돈 200,000원, 고정지출 37,900원(교통 30,000 + 음악 구독 7,900)

| 단계 | 계산 | 결과 |
|---|---|---|
| 이번 달 저축액 | (180,000 − 45,000) ÷ 3 | 45,000원 |
| 이번 달 쓸 수 있는 돈 | 200,000 − 37,900 − 45,000 | 117,100원 |
| 하루 한도 (31일 기간 첫날) | 117,100 ÷ 31 | 약 3,770원 |

- **한도를 넘긴 날**: 넘친 돈은 '어제까지 쓴 돈'에 들어가 남은 날에 자동으로 나눠집니다. 잔소리 대신 "내일부터 하루 ○○원"으로 안내합니다.
- **큰 지출**(하루 한도의 3배 이상): 남은 날에 나눠 반영했다고 따로 알려 줍니다.
- **예정 지출**: 그날까지 하루 한도에서 미리 빼 둡니다.

## 게임 요소

| 요소 | 규칙 | 숫자 바꾸는 곳 |
|---|---|---|
| 도토리 | 하루 한도 지킴 +30, 무지출 +20, 퀴즈 정답 +10, 저축 기록 +50, 7일 연속 +70 | `config.js` REWARD |
| 하루 마감 | 앱을 열면 지난 날들을 자동으로 정산해 보상 | — |
| 레벨 | 지금까지 모은 도토리 합계로 결정 | `config.js` LEVELS, `content.js` LEVEL_TITLES |
| 상점 | 도토리로 모자 · 안경 · 목도리를 사서 입히기 | `content.js` SHOP |
| 경제 퀴즈 | 하루 3문제, 날짜마다 다른 문제 | `content.js` QUIZZES |

## 돈구리 코치 (데모 AI)

지금은 `config.js`의 `AI_MODE: "demo"` — 정해 둔 규칙으로 분석합니다.

- 최근 7일 가장 많이 쓴 카테고리 → 한 번 줄이면 하루 한도가 얼마나 느는지
- 하루 한도가 1,500원보다 낮으면 → 목표일을 한 달 늦췄을 때의 하루 한도
- 연속 기록, 목표 진행률
