# 돈구리 v0.3 — 오늘 써도 되는 만큼

> 2026 CODE 트랙1 · 구일고 0.91 · 운영사 제공 프로토타입
> 참으라고 하지 않고, 목표에서 거꾸로 계산해 **오늘 써도 되는 돈**을 알려 주는 생활 경제 코치 앱

## 실행

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭합니다 (크롬 권장). 인터넷이 없어도 동작합니다 (글꼴만 기본 글꼴로 바뀜).
3. 처음 화면에서 **처음부터 설정하기** 또는 **데모로 둘러보기**를 고릅니다.

기록은 이 기기의 브라우저에만 저장됩니다. **데모 기록은 내 기록과 따로 저장**되고, 설정(오른쪽 위 톱니) → 데모 끝내기로 돌아옵니다.

## 핵심 계산 — 본선에서 설명할 수 있어야 합니다

```
오늘 쓸 수 있는 돈 = ( 한 달 용돈
                      − 고정지출
                      − 이번 달 저축액
                      − 이번 기간 남은 예정 지출
                      − 이번 기간 어제까지 쓴 돈 ) ÷ 남은 날(오늘 포함)

이번 달 저축액 = (목표 금액 − 이미 모은 돈) ÷ 목표일까지 용돈 받는 횟수   (100원 단위 올림)
```

홈의 **‘왜 이 금액일까?’**를 누르면 내 숫자로 이 계산이 한 줄씩 펼쳐집니다.

**예시** — 목표 무선 이어폰 180,000원, 이미 45,000원, 3달 남음, 한 달 용돈 200,000원, 고정지출 37,900원(교통 30,000 + 음악 구독 7,900)

| 단계 | 계산 | 결과 |
|---|---|---|
| 이번 달 저축액 | (180,000 − 45,000) ÷ 3 | 45,000원 |
| 이번 달 쓸 수 있는 돈 | 200,000 − 37,900 − 45,000 | 117,100원 |
| 하루 한도 (31일 기간 첫날) | 117,100 ÷ 31 | 약 3,770원 |

- **한도를 넘긴 날**: 넘친 돈은 '어제까지 쓴 돈'에 들어가 남은 날에 자동으로 나눠집니다. 잔소리 대신 "내일부터 하루 ○○원"으로 안내합니다.
- **큰 지출**(하루 한도의 3배 이상): 남은 날에 나눠 반영했다고 따로 알려 줍니다.
- **예정 지출**: 그날까지 하루 한도에서 미리 빼 둡니다. 날짜가 지나면 **‘썼어요 / 날짜 변경 / 안 썼어요’**를 물어봅니다. ‘썼어요’를 누르면 지출 기록으로 옮겨지고, 예정 금액은 빠져서 두 번 빼지 않습니다.

## 하루 정산 — 기록한 만큼 정확하게

| 그날의 상태 | 어떻게 정해지나 | 도토리 |
|---|---|---|
| 한도 안 | 지출을 기록했고 하루 한도 안 | +30 |
| 무지출 | 지출 없이 **‘오늘 안 썼어요’**(또는 지난 날 ‘이날 안 썼어요’)로 확인 | +50 (30 + 20) |
| 한도 넘음 | 기록한 지출이 한도보다 많음 — 남은 날에 나눠 줌 | 0 |
| 미기록 | 지출도 확인도 없음 | 0 · 연속 기록 끊김 |

- 지난 날을 나중에 기록하거나 고치면 **그날부터 다시 정산**합니다. 더 받을 몫이 생기면 차액만 주고, 이미 받은 도토리를 두 번 주거나 빼앗지 않습니다.
- 지출을 눌러 금액 · 이름 · 날짜를 **고치거나 지울** 수 있습니다. 자주 쓰는 지출은 버튼 한 번으로 채워집니다.
- **저축했어요**는 실제로 옮긴 금액을 적습니다. 이번 용돈 기간 계획만큼 모이면 도토리 +50 (기간마다 한 번).

## 계획 바꿔 보기

코치 카드의 **‘계획 바꿔 보기’**에서 목표일 · 목표 금액 · 고정지출을 바꿨을 때의 **이번 달 저축 · 오늘 하루 한도**를 지금 계획과 나란히 비교합니다. ‘이 계획으로 바꾸기’를 눌러야 실제로 바뀝니다.

## 게임 요소

| 요소 | 규칙 | 숫자 바꾸는 곳 |
|---|---|---|
| 도토리 | 한도 안 +30, 무지출 확인 +20 추가, 퀴즈 정답 +10, 저축 계획 달성 +50, 7일 연속 +70 | `config.js` REWARD |

| 연출 | 기록하면 남은 돈 숫자가 바뀌는 모습, 저축하면 도토리가 저축통으로, 목표 달성 때 돈구리 환호 | `style.css` (기기의 ‘동작 줄이기’ 설정을 따름) |

## 기록 지키기

- 설정 → **기록 내보내기**: 지금 기록을 `.json` 파일로 받아 둡니다. **기록 가져오기**: 그 파일로 되돌립니다 (지금 기록이 바뀌므로 두 번 눌러 확인).
- 브라우저가 저장을 막으면 화면에 알려 줍니다.
- v0.2에서 쓰던 기록은 처음 열 때 자동으로 옮겨 옵니다. 이미 받은 도토리와 꾸미기는 그대로입니다.

## 돈구리 코치 (데모 AI)

지금은 `config.js`의 `AI_MODE: "demo"` — 정해 둔 규칙으로 분석합니다.

- 기록이 없는 날이 있으면 → ‘안 썼어요’ 확인 안내
- 최근 7일 가장 많이 쓴 카테고리 → 한 번 줄이면 하루 한도가 얼마나 느는지
- 하루 한도가 1,500원보다 낮으면 → 목표일을 한 달 늦췄을 때의 하루 한도
- 연속 기록, 목표 진행률

실제 AI 연동 방식은 10.31 통합 멘토링에서 정합니다. **API 키를 코드에 넣지 마세요.**
