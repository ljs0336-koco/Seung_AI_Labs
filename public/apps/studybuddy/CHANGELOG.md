## v0.3 (2026-10-13) — 운영사 · 앱 수정 조언 반영
- [게임 흐름] 한 단원 = 한 스테이지: 설명 → 빠진 개념 되묻기 → 반문 → (일차함수) 그래프 슬라이더 도전 → 새 예시 적용 → 결과
- [홈] 버디의 학습 방 · 오늘의 미션 · 학습 지도(장소 5곳, 적용에 성공하면 다음 장소 열림) · 오늘의 퀘스트 · 다음 보상 미리보기
- [메뉴] 6개 → 3개(모험 · 복습 · 버디), 설정은 톱니로. 랭킹은 ‘예시 랭킹(가상 참가자, 이번 주 XP)’으로 표시
- [판정] 너무 짧은 키워드(a · b · 는 · 은) 정리, 두 단어를 함께 말해야 하는 개념(with), 오개념 짚기(traps), 단어만 나열한 설명은 문장으로 다시 부탁. 키워드 하나로 단원 전체가 통과되던 문제 해결 — 빠진 개념을 차례로 확인하고 적용까지 해야 완료
- [별] 별 1 설명 · 별 2 반문 · 별 3 적용, 힌트 뒤 성공도 인정, 단원별 최고 기록 유지
- [보상] 보상 장부로 같은 성취 중복 지급 방지(반복 성공·반복 실패 XP 없음), RETRY_SUCCESS · DAILY_QUEST · STREAK_BONUS 실제 연결, 연속 학습은 학습한 날 기준
- [복습] alert 대신 화면 안 해설 카드, 문항마다 즉시 저장 · 중단 후 이어 풀기, 복습 완료 도장 · 마스터 배지, “지난번에 알려 준 걸 다시 해 보자”
- [연출] 버디 숨쉬기 · 눈 깜박임 · 끄덕임 · 갸웃+물음표 · 격려 · 점프 · 포즈, 결과 화면(별 순서대로 → XP 차오름 → 레벨업 · 해금 · 색종이), 건너뛰기, 움직임 줄이기 · 효과음(기본 꺼짐)
- [성장] 새싹 → 탐구 → 연구 버디(머리 위 새싹 · 가슴 배지 · 빛), 학습 방 소품이 늘어남, 버디를 누르면 배운 내용을 떠올림
- [버디 탭] 꾸미기 · 개념 도감(함께 배운 내용 · 내가 고친 설명 · 다음 복습일) · 최근 기록(이해 완료 / 복습 필요 구분)
- [설정] 해금 레벨을 config.js `UNLOCKS` 한곳으로, 성향 검사 다시 하기는 기록 유지, 데모 기록 분리(시작 XP 40 → 첫 단원 완료로 Lv.2 · 학사모)
- [디자인] 보라 · 민트 · 노랑 학습 RPG 톤, 입체 버튼, 이모지 대신 아이콘
