# STUDY-BUDDY v0.2 — 내가 가르치며 자라는 AI 학습 버디

> 2026 CODE 트랙2 · 옥종고 OKXEN · 운영사 제공 프로토타입
> AI 학생 '버디'에게 개념을 설명하고, 소크라테스 반문에 답하며 함께 성장하는 메타인지 에듀테크 앱

## 실행 방법

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭합니다 (크롬 브라우저 권장). 인터넷이 없어도 100% 오프라인 동작합니다.
3. 처음 화면에서 **성향 검사 6문항**을 풀거나 **데모로 둘러보기**를 선택합니다.
4. 휴대폰 화면으로 보기: `F12` → `Ctrl + Shift + M`

기록은 사용 중인 기기의 브라우저 로컬 저장소(localStorage)에만 안전하게 보관됩니다.

## 파일 구조 — 어디를 고치면 무엇이 바뀌나

| 파일 | 역할 | 수정 가이드 |
|---|---|---|
| `data/content.js` | 성향 검사, 5대 단원 개념, 소크라테스 반문 질문, 퀴즈, 대사, 랭킹 | ✏️ 마음껏 수정 |
| `data/config.js` | 경험치 보상 수치, 레벨 문턱, 복습 간격, 해금 기준 | ✏️ 숫자만 수정 |
| `style.css` | 색상, 글꼴, 레이아웃, 애니메이션 (`.is-correct` 등) | ✏️ 자유롭게 |
| `assets/character.js` | 둥근 버디 SVG 캐릭터 렌더러 (표정 6종 + 꾸미기 아이템) | ✏️ 조심해서 |
| `index.html` | 앱 뼈대 컨테이너 | 🔒 기본 유지 |
| `app.js` | 메타인지 가르치기 루프 · 간격 복습 · 데이터 저장 엔진 | 🔒 ENGINE |
| `docs/` | v0.1 데이터 스키마 및 AI 프롬프트 설계 참조 자료 | 참고용 |

## 핵심 메타인지 루프 (본선 심사 발표 핵심)

```
[학생 설명 작성] (20자 이상)
       ↓
[키워드 분석] (누락된 개념 탐지)
       ↓
[소크라테스 유도 질문] (버디가 단원별 핵심 반례나 조건 역질문)
       ↓
[학생 답변 제출]
       ↓
[이해 완료 판정] (+50 XP, 버디 감정 환호, 1일 후 간격 복습 등록)
```

- **망각곡선 간격 복습**: 1일 → 3일 → 7일 → 14일 간격으로 복습 퀴즈를 제공하여 장기기억으로 고착화합니다.
- **4가지 버디 성향**: 호기심형(#2A9D8F), 꼼꼼형(#4C5FD5), 응원형(#E76F51), 도전형(#E9A23B).
- **성장과 보상**: Lv2 학사모, Lv3 목도리, Lv4 안경, Lv5 헤드폰이 해금됩니다.
