# STUDY-BUDDY v0.3 — 내가 가르친 버디와 함께 개념을 정복하는 학습 RPG

> 2026 CODE 트랙2 · 옥종고 OKXEN · 운영사 제공 프로토타입
> 버디에게 개념을 설명하고, 버디의 반문에 답하고, 새 예시에 적용하면 지도 위 장소가 열리고 버디가 자랍니다.

## 실행 방법

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭합니다 (크롬 권장). 인터넷이 없어도 동작합니다 (글꼴만 기본 글꼴로 바뀜).
3. 처음 화면에서 **성향 검사 6문항**을 풀거나 **데모로 둘러보기**를 고릅니다.

기록은 이 기기의 브라우저에만 저장됩니다. **데모 기록은 내 기록과 따로 저장**되고, 설정(오른쪽 위 톱니) → 데모 끝내기로 돌아옵니다.

| 파일 | 하는 일 | 수정 |

| `data/config.js` | XP 보상 · 레벨 표 · 꾸미기 해금 레벨 · 복습 간격 · 연출 시간 | ✏️ 숫자만 |
| `style.css` | 색 · 글꼴 · 버튼 · 버디 움직임. 맨 위 `:root` 색 변수만 바꿔도 분위기가 바뀜 | ✏️ |
| `assets/character.js` | 버디 그림(표정 6종 · 꾸미기 · 성장 3단계)과 학습 방 배경 | ✏️ 조심해서 |

| `app.js` | 스테이지 진행 · 판정 · 보상 장부 · 퀘스트 · 복습 · 저장 | 🔒 ENGINE — 바꾸고 싶으면 요청 시트에 |
| `docs/` | v0.1 스키마 · AI 지시문 참고 자료, 판정 확인 문장 | 참고용 |

## 한 스테이지 = 한 단원 (본선 발표 핵심)

```
지도에서 장소 고르기
  → ① 설명: 내 말로 버디에게 설명 (20자 이상)
       버디가 끄덕이며 메모 → 설명한 개념에 도장, 빠진 개념은 하나씩 되묻기
  → ② 반문: 조건·예외 질문에 근거 있는 답 고르기
  → ③ 도전: (일차함수) a·b 슬라이더로 직선 만들기 → "왜 그렇게 바뀌었을까?"
  → ④ 적용: 처음 보는 예시에서 버디의 풀이를 확인하고 바로잡기
  → 결과: 별 · XP · 레벨업 · 꾸미기 해금 · 다음 장소 열림 · 다음 복습일
```

| 별 | 받는 조건 |
|---|---|
| 별 1 설명 | 핵심 개념을 설명했거나, 빠진 개념을 되묻기에서 보완했다 |
| 별 2 반문 | 조건·예외 질문을 해결했다 (힌트를 본 뒤에 맞혀도 받음) |
| 별 3 적용 | 새 예시에서 버디의 풀이를 바르게 확인했다 → **다음 장소가 열림** |

- 두 번 틀리면 정리 카드를 보여 주고 그 개념은 복습에서 다시 만납니다. 별은 이번에 못 받아도, 다시 도전해서 모을 수 있습니다.
- 지금 버디는 **데모 버디**입니다. 정해 둔 질문과 키워드로 판정하고, 단어만 늘어놓은 설명은 문장으로 다시 부탁합니다. 실제 AI 연결은 10.31 통합 멘토링에서 정합니다. **API 키를 코드에 넣지 마세요.**

## 보상 — 같은 성취로는 한 번만

| 활동 | XP | 기준 |
|---|---|---|
| 한 단원 별 3개 (힌트 없이) | 50 | 단원마다 한 번 |
| 한 단원 별 3개 (힌트 보고 보완) | 30 | 나중에 힌트 없이 성공하면 차액 20만 추가 |
| 예정된 복습 문제 정답 | 20 | 복습 회차·문항마다 한 번, 푸는 즉시 저장 |
| 오늘의 퀘스트 3개 | 40 | 하루 한 번 (설명 · 반문 · 적용, 복습이 있는 날은 세 번째를 복습으로 대신) |
| 7일 연속 학습 | 50 | 접속이 아니라 실제로 학습한 날 기준 |

틀리기만 반복하거나 같은 설명을 다시 내는 것으로는 XP가 쌓이지 않습니다. 숫자는 `config.js`의 `REWARD`에서 바꿉니다.

- 평소에는 숨쉬기 · 눈 깜박임, 설명을 쓰는 동안에는 멈춥니다.

- 결과 화면은 **건너뛰기**가 있고, 보상은 연출 전에 이미 저장됩니다.

## 단원 더하기 (content.js)

`UNITS`의 단원 하나를 통째로 복사해서 고칩니다. 필요한 칸: `place`(장소 이름) · `goal` · `concepts`(설명에서 확인할 개념과 되물을 질문) · `check`(반문) · `apply`(새 예시) · `learned`(결과 화면 3줄) · `quizzes`(복습 문제). `challenge`(슬라이더 도전)는 일차함수에만 있고 없어도 됩니다. 각 칸의 뜻은 `content.js` 위쪽 설명에 있습니다.

AI에게는 이렇게 말하면 됩니다: *“content.js의 단원 목록에 기존과 같은 형식으로 ‘(과목) (단원)’ 단원을 하나 더해 줘. 반문 보기마다 이유를 담고, 틀린 보기에는 짧은 설명(why)을 붙여 줘. 다 하면 추가한 내용을 표로 보여 줘.”*

판정이 잘 되는지 확인하는 문장은 `docs/판정_확인문장_v0.3.md`에 있습니다.
