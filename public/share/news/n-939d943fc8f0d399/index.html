OpenAI 'dots', 코딩 도구를 '항상 켜진 개인 비서'로

OpenAI가 코딩 도구 Codex의 기능을 다듬어, 시키지 않아도 일정·메일을 챙기는 개인 비서 dots로 내놨습니다. 사용자 정보를 주기적으로 살펴 먼저 제안하는 방식이라, 어디까지 데이터를 내주는지가 쟁점입니다.

자세한 요약

  • dots는 OpenAI가 9월 말 개발자 행사에서 공개한 개인 비서로, ChatGPT 앱 Pro 이상 요금제(월 100달러부터)에서 캘린더·메일·컴퓨터에 연결해 일정 충돌과 마감을 먼저 알려 줍니다.
  • OpenAI 기업 제품팀을 이끄는 Alexander Embiricos는 10월 TechCrunch Disrupt에서 기능 대부분이 Codex로도 되지만 손이 많이 가, 새 기술보다 사용 경험을 바꾼 제품이라고 설명했습니다.
  • 지인 프로필을 만든다고 비판받은 Meta의 비서 Muse처럼 dots도 데이터를 모으느냐는 질문에, Embiricos는 그렇다며 주기적으로 사용자 정보와 받은 권한을 살펴 도울 일을 제안하는 능동 조사 기능을 소개했습니다.
  • 기자는 에이전트와 모회사의 데이터 수요를 떼어 보기 어렵다고 짚었고, 경쟁사 Hark는 OpenAI·Meta와 달리 광고 사업용 데이터를 모으지 않는다고 내세웁니다.
  • OpenAI는 학습 사용 끄기와 접근 범위 선택 등 ChatGPT와 같은 개인정보 설정을 준다고 했지만, 기자는 설정이 세밀하지 않고 클라우드 드라이브 읽기 전용 권한은 받아들이지 않는다고 지적했습니다.
  • Embiricos는 아주 세밀한 권한 설정을 만들어야 한다며 출시 때 허락을 너무 자주 물어 비판받은 점은 차차 조정하겠다고 했고, 결제 처리 회사들과 깊이 논의 중이라고 밝혔습니다.
