S-1로 본 Anthropic 전략: Claude Code 쓰는 기업 고객이 20배 더 지출

대형 고객 절반 이상이 API와 Claude Code 같은 자체 앱을 함께 쓰며, 클라우드 3사와의 경쟁을 위험 요인으로 적었습니다.

자세한 요약

  • 연 10만 달러 이상 쓰는 고객 약 1.19만 곳 중 절반 이상이 API와 Claude Code·Cowork 같은 자체 앱을 함께 씁니다(지난해 말 약 30%).
  • 3분기 Claude Code를 쓰는 상위 5% 기업 고객은 쓰지 않는 평균 고객보다 매달 약 20배를 지출했습니다.
  • AWS·Google Cloud·Azure를 통해 판매하지만, 신청서는 이 회사들이 점점 경쟁자가 되어 컴퓨팅 확보가 어려워질 수 있다고 경고했습니다.
  • Claude Code 단독 매출은 공개되지 않았습니다.
