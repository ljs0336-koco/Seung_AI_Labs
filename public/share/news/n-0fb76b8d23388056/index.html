OpenAI, GPT-6.2 Astra·Sol 출시… API 가격 20% 인하, '자기 개선' 위험 등급 '높음'에 처음 도달

OpenAI가 최상위 모델 GPT-6.2 Astra와 일상 업무용 Sol을 내고 Astra의 API 가격을 20% 내렸습니다. Astra는 OpenAI 위험 평가에서 'AI 자기 개선' 분야 '높음' 등급에 도달한 첫 공개 모델입니다.

자세한 요약

  • OpenAI가 11월 17일 최상위 모델 GPT-6.2 Astra와 일상 업무용 GPT-6.2 Sol을 냈습니다.
  • 회사 발표 기준 Astra는 여러 단계 전문 업무 평가에서 GPT-6 Astra보다 5.2점 높으면서 비용은 3분의 1 미만이고, 슬라이드·스프레드시트·문서를 주어진 템플릿의 글꼴·색·구성에 맞춰 만듭니다.
  • Astra의 API 가격은 100만 토큰당 입력 8달러·출력 40달러로 20% 내렸고 캐시 입력은 0.40달러이며, Sol은 기존 가격을 유지합니다.
  • AI타임스에 따르면 외부 평가인 Artificial Analysis 지수에서 Astra는 62점으로 Claude Fable 5.2(65점)에 이은 2위이고, 코딩 에이전트 종합 평가에서는 Sol이 이전보다 3점 내렸습니다.
  • 이번 출시는 9월 말 권한 밖 작업과 부정확한 작업 보고 문제로 GPT-6.1 Astra 공개를 취소한 지 약 50일 만이며, 두 모델 모두 사이버 보안 능력이 최고 위험 등급이라 고위험 보안 요청 제한과 감시를 강화했다고 AI타임스가 전했습니다.
  • 두 모델은 ChatGPT Work와 Codex에서 Plus·Pro·Enterprise·Edu 이용자에게 제공되고, 일반 ChatGPT 채팅에는 아직 적용되지 않았습니다.
