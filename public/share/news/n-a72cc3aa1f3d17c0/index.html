Anthropic, 코드 검토·수정·승인을 에이전트에 맡기는 'Claude Ship' 베타 출시

Anthropic이 11월 23일 코드 변경의 검토·수정·승인을 자동화하는 에이전트 묶음 Claude Ship을 내놨습니다. 팀이 저장소에 글로 적어 둔 정책에 따라 AI가 변경을 승인하는 기능이 들어 있어, 승인 권한을 에이전트에 맡기는 첫 시도로 꼽힙니다.

자세한 요약

  • Anthropic은 11월 23일(미국 시각) 일상적인 코드 변경의 검토·수정·승인을 자동화하는 에이전트 묶음 Claude Ship을 베타로 발표했습니다.
  • 구성은 이미 정식 제공 중인 Code Review와 새로 베타로 나온 PR Steward, Claude Approvals 세 가지입니다.
  • PR Steward는 자동 검사 실패, 병합 충돌, 리뷰 지적을 고치고, 푸시할 때마다 무엇을 바꿨는지와 되돌리는 방법을 댓글로 남깁니다.
  • Claude Approvals는 팀이 저장소에 자연어로 써 둔 승인 정책 파일을 적용하며, 코드 리뷰 결과나 회사 자체 분류기 같은 신호를 함께 볼 수 있습니다.
  • Anthropic은 승인 기능을 먼저 관찰 전용 모드로 돌려 보고, 저장소 하나부터 시작해 월 지출 한도를 걸라고 권했으며, 어떤 변경을 사람에게 넘길지는 팀이 정한다고 밝혔습니다.
  • 회사 블로그는 Claude Code 팀의 코드 대부분을 Claude가 쓰고 있어 그 뒤 단계도 같은 속도로 움직이게 하려 했다고 설명했고, 제품은 GitHub 저장소를 쓰는 Claude Team·Enterprise 플랜에 차례로 제공됩니다.
