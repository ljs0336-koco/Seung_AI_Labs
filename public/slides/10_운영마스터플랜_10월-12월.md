## 4. 프로토타입 제작 표준 (v0 기준)

학생이 **AI로 안전하게 고칠 수 있는 구조**가 목표입니다. 이후 전문가 보강(v2~)도 같은 기준을 지킵니다.

### 4-1. 폴더 구조

```
팀명_v0_1014/
├── index.html        화면 뼈대 (어떤 화면·버튼·글자가 있는지)
├── style.css         디자인 (색·글꼴·크기·배치)  ※ 색은 :root CSS 변수로 모으기
├── app.js            동작 (계산·화면 전환·점수·저장)
├── data/
│   ├── content.js    콘텐츠: 퀴즈·대사·아이템·AI 프롬프트 문구  ← 학생이 가장 많이 고치는 곳
│   └── config.js     규칙 숫자: 보상 포인트·레벨 경험치·한도 계산 파라미터
├── assets/           이미지·아이콘·효과음
├── README.md         실행 방법 + 파일 설명 + 🔒/✏️ 구역 안내
└── CHANGELOG.md      버전별 변경 기록
```

### 4-2. 제작 규칙

1. **빌드 도구 없이** `index.html` 더블클릭으로 실행 (크롬). 학생 환경을 단순하게 유지합니다.
2. 데이터 파일은 **`.js`로** (`window.CONTENT = {...}`). `file://`로 열면 `.json` 불러오기(fetch)가 브라우저에서 막히기 때문입니다.
3. 저장은 `localStorage`. **키에 버전 붙이기** (`studybuddy_v2_state`) → 구조가 바뀌어도 이전 데이터와 충돌하지 않습니다.
4. 코드 구역 표시: `/* 🔒 ENGINE: 수정 전 운영사 문의 */`, `/* ✏️ EDIT: 학생 수정 가능 */`
5. 파일당 **300~500줄 이내**로 나눕니다. AI에 통째로 붙여넣기 쉽고, 붙여넣기 실수도 줄어듭니다.
6. 함수마다 **한국어 한 줄 주석** (학생이 본선 Q&A에서 설명할 수 있도록).
7. **AI 기능은 '데모 모드' 기본**: 미리 쓴 응답으로 동작하고, 실제 API는 스위치(`config.js`의 `AI_MODE`)로 전환합니다. **API 키를 코드에 넣거나 드라이브에 올리지 않습니다.**
8. 모바일 우선 (가로 390px 기준) + PC에서도 깨지지 않게.
9. 시연용 **'데모 데이터 불러오기 / 초기화' 버튼** (본선 무대에서 바로 보여줄 상태 만들기).

### 4-3. 팀별 v0 범위 (1차 멘토링 후 확정)

| 구일고 『돈구리』 | 옥종고 『STUDY-BUDDY』 |
|---|---|
| ① 목표·기한·수입·고정지출 입력 → **오늘의 추천 한도** 계산 | ① 성향 검사 → **나만의 AI 학생 캐릭터** 생성 |
| ② 지출 기록 → 남은 한도 실시간 감소, 초과 시 재계산 | ② **가르치기**: 개념 설명 입력 → AI 학생의 되묻기·퀴즈 (데모 모드) |
| ③ 일일 경제 퀴즈 → 포인트 → 상점·캐릭터 꾸미기 | ③ 경험치·레벨업·보상 (게임 루프) — 시즌 리그는 v2 이후 |
