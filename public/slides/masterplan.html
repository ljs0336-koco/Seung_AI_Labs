04 프로토타입 제작 표준 & 옥종고 Godot 4 조건부 지원

기본 베이스는 학생이 AI로 안전하게 고칠 수 있는 순수 정적 웹 구조를 채택하며, 옥종고(OKXEN)가 희망하는 Godot 4(GDScript)는 개발자 멘토 지원 아래 공통 JSON 데이터 스키마(STUDYBUDDY_학습기록.json)를 공유하는 조건부 작은 시도로 검증합니다.

팀명_v0_1014/
├── index.html        화면 뼈대 (HTML5)
├── style.css         디자인 (:root CSS 변수)
├── app.js            동작 및 이벤트 로직
├── data/
│   ├── content.js    콘텐츠: 퀴즈·대사·프롬프트 (학생 집중 수정 구역)
│   └── config.js     규칙 숫자: 보상·경험치·한도 계산 파라미터
├── assets/           이미지·아이콘·효과음
├── README.md         실행 방법 및 구역 안내
└── CHANGELOG.md      버전별 변경 기록
1. 구일고(돈구리): 가상 원화(sim_won, 모의 지갑↔목표 저축통)와 도토리(acorn_points, 보상 원장)를 분리하고, 잔액 부족 거절·중복 요청(request_id) 차단·반대 거래(reverse) 취소를 적용합니다.
2. 옥종고(STUDY-BUDDY): 사실 검증을 통과한 기억(SIM-MEM-01)만 승인·저장(saved: true)하고, Godot 4 시도 시 C# 혼용 없이 GDScript 단일 언어로 1개 단원(일차함수)에서 [설명 입력 → 버디 반응 → 로컬 JSON 저장·복원 → 고정 응답 연결]을 먼저 검증합니다.
3. API 키 보안: 코드·씬 파일 안에 OpenRouter 등 실제 API 키를 직접 넣지 않으며, 기본 시연은 안전한 고정 응답/데모 모드로 동작합니다.
