02앱의 구조

파일 이름을 알면, 말하기가 쉬워진다

파일하는 일이런 걸 바꾸고 싶을 때
index.html화면에 무엇이 있는지 — 집의 뼈대화면 · 버튼 · 글자 추가
style.css어떻게 보이는지 — 인테리어색 · 글꼴 · 크기 · 간격 · 배치
app.js누르면 무슨 일이 일어나는지 — 전기 배선계산 · 화면 전환 · 점수 · 저장
data/content.js앱 속 내용물퀴즈 · 대사 · 아이템 · AI 지시문
data/config.js게임 규칙 숫자보상 포인트 · 레벨 기준 · 한도
assets/그림 · 아이콘 · 소리캐릭터 이미지 교체
CHANGELOG.md버전별 변경 기록버전을 올릴 때마다
부담 없는 곳부터내용 → 모양 → 기능
content.js · config.js↓ style.css↓ index.html↓ app.js — 바꾸기 전에 설명부터
ENGINE 표시

계산 · 저장 같은 앱의 심장입니다. 바꾸고 싶어지면 요청 시트에 적어 주세요. 함께 봅니다.

EDIT 표시

마음껏 바꿔도 되는 곳입니다.

05말하는 법

AI에게 말할 때 네 가지

빈칸만 채워서 말해 보세요
무엇을
○○ 화면의 ○○를
어떻게
~~~ 하게 바꾸고 싶어. (숫자 · 색 · 예시가 있으면 함께)
그대로
다른 기능과 디자인은 그대로 두고, ENGINE 표시 부분은 건드리지 마.
순서
  • 바꾸기 전에 어떻게 할지 먼저 알려 줘.
  • 끝나면 무엇을 바꿨는지 쉽게 3줄로.
더 잘 통하는 네 가지Tips
  1. 01
    한 번에 한 가지작게 맡기면 결과를 확인하기 쉽고, 틀려도 금방 되돌립니다.
  2. 02
    숫자 · 색 · 예시를 준다모호하면 AI가 마음대로 정합니다.
  3. 03
    화면을 캡처해 보여 준다말로 설명하기 어려운 모양은 캡처 한 장이 가장 빠릅니다.
  4. 04
    대화가 길어지면 새로 연다AI가 앞 내용과 헷갈립니다. 새 대화에서 “지금 상태를 확인하고 이어서 해 줘”.
07말하는 법 Claude Code · Codex · ChatGPT 등 어떤 AI를 써도 같은 방식이 통합니다.

06모호한 말과 좋은 말

모호하게 말하면, AI가 마음대로 정한다

모호한 말

결과가 매번 달라진다

원하지 않은 곳까지 바뀌기 쉽다.

디자인
“예쁘게 해줘”
콘텐츠
“퀴즈 기능 만들어줘”
오류
“오류 고쳐줘”
좋은 말

무엇을, 어떻게, 얼마나

본 것 · 원하는 결과 · 구체적인 값.

디자인
메인 배경을 연한 민트(#E8F8F5)로, 버튼 모서리를 조금 더 둥글게 바꿔 줘
콘텐츠
퀴즈에 기존과 같은 형식으로 5문제 더해 줘. 고1 수준, 보기 4개, 해설 1줄
오류
저장 버튼을 눌러도 아무 반응이 없어. 캡처 첨부할게. 원인부터 찾아서 설명해 주고 고쳐 줘
본선 대비

“○○ 기능이 어떻게 동작하는지 고1이 이해하게, 예시 숫자로 한 단계씩 설명해 줘.”

심사위원은 동작 원리를 묻습니다
08모호한 말과 좋은 말 AI가 만든 기능도 우리가 설명할 수 있으면 우리 것입니다.

07하고 싶은 것별 예시

하고 싶은 것부터 찾는다

하고 싶은 것이렇게 말해 보기
A글자 · 문구“첫 화면 인사말을 ‘○○’로 바꿔 줘”
B색 · 분위기“전체 색을 ○○ 느낌으로. style.css 맨 위 색 변수만 바꿔 줘”
C그림 바꾸기“assets 폴더에 넣은 그림을 캐릭터로 써 줘”
D내용 늘리기“퀴즈를 기존과 같은 형식으로 5개 더”
E규칙 숫자“보상을 조금 더 후하게. config.js 숫자만 바꾸고 표로 보여 줘”
F새 화면 · 버튼오른쪽 예시
G잘 안 될 때다음 장
H휴대폰에서 깨짐“휴대폰 화면에서 ○○가 넘쳐. 캡처 첨부할게”
예시 · F

새 화면 추가하기

메인 화면에 ‘내 기록’ 버튼을 추가하고, 누르면 지금까지 저장된 기록을 최신순 목록으로 보여 주는 새 화면을 만들고 싶어. 뒤로 가기 버튼도 필요해.

지금 앱의 화면 전환 방식을 그대로 따라 줘. ENGINE 표시 부분은 건드리지 마.

03

되돌리고 넘어가기

“방금 바꾼 것 되돌려 줘” 또는 처음 받은 zip에서 다시. 몇 번 해도 안 되면 요청 시트에 적고 다른 일부터 하세요.

자주 보는 증상이렇게 말해 보기
화면이 하얗게 나온다“화면이 하얗게만 나와. 원인 찾아 줘” — 대개 작은 문법 실수

예전 기록 때문에 이상하다앱 설정의 초기화

09우리의 약속

나머지는 자유, 이것만 함께

  1. 01
    API 키 · 비밀번호는 넣지 않는다

    드라이브에 올리는 것은 공개하는 것과 같습니다. AI 도구가 키를 넣자고 하면 멈추고, 실제 AI 연동이 필요하면 운영사에 말해 주세요.

  2. 02
    실제 개인정보는 쓰지 않는다

    이름 · 금액 · 연락처는 모두 가짜 데이터로. AI와의 대화창에도 적지 않습니다.

  3. 03
    남이 만든 그림 · 음악은 출처를 본다

    직접 만든 것, AI로 만든 것, 무료로 써도 되는 것만 씁니다.

  4. 04
    AI가 만든 것도 설명할 수 있게

    모르는 부분은 06장의 ‘본선 대비’처럼 물어보고, 이해한 뒤 넘어갑니다.

11우리의 약속 01과 02는 대회 규정과 개인정보 보호에 관한 것이라 꼭 지켜 주세요.
