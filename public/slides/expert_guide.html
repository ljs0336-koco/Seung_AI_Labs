04기술 요청

학생이 AI로 고쳐도, 깨지지 않게

  1. 01
    빌드 도구 없이 실행

    index.html 더블클릭으로 동작하는 구조를 유지해 주십시오. 프레임워크 · 번들러 도입은 운영사와 협의합니다.

  2. 02
    콘텐츠와 수치를 분리

    data/content.js(퀴즈 · 대사 · AI 지시문), data/config.js(경험치 · 보상). file:// 실행이라 JSON 대신 .js 전역 객체로.

  3. 03
    구역 표시와 짧은 파일

    ENGINE(학생 수정 금지) · EDIT(수정 가능) 주석, 파일당 300–500줄, 함수마다 한국어 한 줄 주석.

  4. 04
    저장 키에 버전 표기

    studybuddy_v2_state처럼 표기하고, 구조가 바뀌면 초기화 또는 마이그레이션.

  5. 05
    AI는 데모 모드가 기본

    미리 쓴 응답을 기본으로 두고 실제 API는 스위치로. API 키가 코드와 드라이브에 남지 않게. 연동 방식은 R1에서 결정합니다.

  6. 06
    시연 안정성과 기록

    오프라인 동작 · 데모 데이터 불러오기와 초기화 버튼 · 배포 URL과 zip 백업. 결과물마다 CHANGELOG.md 갱신.

06기술 요청 학생들은 ChatGPT · Gemini · Claude 등에 파일을 붙여넣어 수정합니다.
