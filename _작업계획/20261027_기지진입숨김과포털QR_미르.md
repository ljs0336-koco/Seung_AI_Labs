# 기지 진입 숨김과 현장 제시용 포털 QR

2026-10-27. 시작 기준 9190f25. 사용자 후속 요청.

- 패들렛을 기지의 특강 구역에 추가한다. 메인 헤더·푸터의 기지 링크는 제거하고 기지 주소는 이 대화로만 별도 전달한다. 기지 경로와 기존 자료는 보존한다.
- 제목 바로 오른쪽에 작은 QR 상자를 두고 누르면 확대 대화상자로 보여준다. QR 대상은 query/hash 없는 통합포털 대표 주소다. 닫기·Escape·바깥 클릭과 키보드 초점은 기본 modal dialog 동작으로 제공한다.
- 미르: 통합·QR UI·검증·게시. B: 자료 등록 계약 읽기 전용 확인. C: QR 생성과 독립 디코딩. D: 별도 코드 검토.
- 기존 간행물 지면·공전·노출 체계는 유지. 새로운 로그인이나 호스팅 이전 범위는 아니다.

구현·검증 완료: Padlet은 lecture/base 독립 링크로 등록(revision7, 자료20개). 기지의 특강 목록·열기·검색·복사 흐름을 사용하며 메인에는 표시하지 않는다. 헤더·푸터의 기지 링크를 모두 제거했다.

QR: 대표 주소 https://ljs0336-koco.github.io/Seung_AI_Labs/ 의 정적 SVG. ECC M, 사방4모듈흰여백. 별도 qrcode 생성기와 jsqr+pngjs 해독기로 URL 완전일치 확인. 실제 브라우저 확대 화면 캡처도 해독해 같은 URL임을 재확인했다. 생성·해독 패키지는 대화 작업폴더에만 설치했고 제품 의존성은 추가하지 않았다.

검증: Portal/BasePage 기존 테스트8개, 변경 JSX lint, production build와 public/src/dist 개인정보 검사 통과. 독립 코드 검토에서 추가 P1/P2 결함 없음. 실제1440px에서 제목옆50px QR와 확대540px 확인; 클릭·닫기·Escape·원래버튼초점복원 확인. 320px에서44px정사각QR·모바일확대·가로넘침없음 확인. 메인 base 링크0개, 기지 특강의 Padlet href 일치 확인.
